Hermes Skeleton

A personal Hermes Agent setup, published as a reusable skeleton.

About the "Hermes" app. This page is also the homepage of Hermes, a private, single-user assistant. It runs on its owner's own server and acts only for that one person. It is not a public service, and nobody else can sign up for it or use it. See the privacy policy.

What this repository is

The code that turns a stock Hermes Agent install into this particular setup, without forking Hermes:

  • Plugins: a long-term memory ("brain") with automatic fact extraction and a separate approver, a per-channel topic router, quiet background notifications, and approval-expiry notices.
  • A password vault as an MCP server, so the agent can use secrets without ever seeing them.
  • Maintenance scripts for nightly brain tidying, daily reports and housekeeping.
  • A config overlay holding only the settings that differ from Hermes's defaults.
  • A pinned upstream version with install and update scripts, so updates move to a tested commit instead of whatever is newest.

What it is not

It holds no secrets, personal configuration, conversation data or memories. Those live on the owner's server and in a separate private repository.
