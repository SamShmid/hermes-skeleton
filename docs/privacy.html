Hermes Privacy Policy

Last updated: October 7, 2026

"Hermes" is a personal assistant app run by one person (the "owner") for their own use. It is not a product or a public service. Only the owner's own accounts are ever connected to it, and only the owner can use it.

What data Hermes accesses

When the owner connects their Google account, Hermes may access the Google data the owner grants it, such as email, calendar or files. It does this only to carry out the owner's own requests (for example "summarize today's email" or "what's on my calendar tomorrow"). It does not access anyone else's account.

How the data is used

  • Only to provide assistant features to the owner.
  • Not for advertising, profiling, or training AI models.
  • Not sold, rented or shared with anyone.

Where the data is stored

On the owner's own server. OAuth tokens and anything Hermes keeps (for example notes it remembers for the owner) stay there. Nothing is stored by the author of this code or by any hosting service run for this app.

Third parties

To answer a request, Hermes sends the relevant text to the AI model provider that the owner has chosen and configured. That provider processes it under its own terms and privacy policy. Besides that model provider and Google itself, no third party receives the data.

Google API Services User Data Policy

Hermes's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Keeping and deleting data

The owner can revoke Hermes's access at any time in their Google Account settings (Third-party apps with account access) and can delete any stored data from their own server.

Changes

If this policy changes, the new version will be posted on this page with a new date.

Contact

Questions about this policy: open an issue on this project's GitHub repository.
